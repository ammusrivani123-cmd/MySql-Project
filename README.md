🎵 Music Store Data Analysis Using SQL

📌 Project Overview

The Music Store Data Analysis project uses SQL to analyze music store sales data and uncover business insights related to customer purchasing behavior, revenue generation, music genres, and sales trends.

The project demonstrates how SQL can be used to solve real-world business problems and support data-driven decision-making.

🎯 Project Objectives

* Analyze customer purchasing patterns and spending behavior.
* Identify countries with the highest invoice counts.
* Find the top-spending customers.
* Explore popular music genres and artists.
* Analyze country-wise music preferences.
* Generate actionable business insights from sales data.

🛠️ Tools & Technologies

* SQL
* MySQL
* MySQL Workbench
* Relational Database Management

🗂️ Database Overview

The Music Store database consists of multiple related tables that store information about customers, invoices, tracks, albums, artists, employees, and music genres.

Key tables include:

* customer
* invoice
* invoice_line
* track
* album
* artist
* genre
* employee

These tables help analyze customer transactions, music preferences, and sales performance.

💻 SQL Concepts Used

* SELECT, WHERE, ORDER BY
* Aggregate Functions: SUM(), COUNT(), AVG()
* GROUP BY and HAVING
* Joins
* Subqueries and Correlated Subqueries
* Common Table Expressions (CTEs)
* Window Functions: RANK() and DENSE_RANK()
* Views
* Stored Procedures
* Filtering, Sorting, and Data Aggregation

🚀 How to Run the Project

1. Clone or download this repository.
2. Set up the Music Store database in MySQL.
3. Open MySQL Workbench and connect to your MySQL server.
4. Open the SQL query file.
5. Execute the queries to explore the data and review the results.

Note: The database setup files must be obtained separately if they are not included in this repository.
